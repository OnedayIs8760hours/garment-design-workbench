# 模板与资源目录规范

## 目的

所有服装品类必须使用同一个英文品类目录名串联模板元数据、浏览器静态资源和 3D 模型。不要再用尺码 ID、临时导出名或 CLO 文件名作为 public 目录名。

## 品类命名

品类目录使用英文 kebab-case：

- 普通橄榄球衣：`football-jersey`
- 橄榄球衣-双拼-露脐：`football-jersey-crop-top-two-tone`

模板 ID 仍保留业务尺码或模板 ID，例如 `M-2XL`、`W-M`。品类目录和模板 ID 是两个概念，不要混用。

## 根目录模板文件

模板元数据统一放在项目根目录 `templates/`：

```text
templates/
  index.js
  football-jersey/
    M-2XL.template.json
    M-2XL.uv_mapping.json
  football-jersey-crop-top-two-tone/
    W-M.template.json
    W-M.uv_mapping.json
```

规则：

- `templates/index.js` 是唯一模板注册入口。
- 每个模板必须有 `*.template.json`。
- 每个支持 3D 预览的模板必须有 `*.uv_mapping.json`。
- 模板事实，包括裁片尺寸、bounds、图层名、mask 路径、guides，都只能写在模板 JSON 中。
- React 组件不能硬编码某个品类的裁片尺寸、坐标或裁片 ID。

## Public 静态资源

浏览器直接加载的裁片图、遮罩图放在 `public/templates/<category>/`：

```text
public/templates/
  football-jersey/
    panels/
    masks/
  football-jersey-crop-top-two-tone/
    up-front/
      panels/
      masks/
    up-back/
      panels/
      masks/
```

规则：

- public 目录名必须和根目录 `templates/<category>/` 保持一致。
- `template.json` 里的 `panelImage`、`maskImage` 仍写相对品类目录的路径。
- `templates/index.js` 中每个模板定义必须配置 `publicAssetBase`，例如 `/templates/football-jersey`。
- 订单导出的 `sourceFile` 应使用 `templates/<category>/...`，不能使用旧的 `templates/M-2XL/...` 或 `templates/W-M/...`。

## 3D 模型命名

GLB 模型放在 `public/models/`，文件名使用品类英文名：

```text
public/models/
  football-jersey.glb
  football-jersey-crop-top-two-tone.glb
```

规则：

- `templates/index.js` 中 `defaultModelUrl` 必须指向上述英文模型名。
- 不再使用临时名，例如 `soccer-new-rename.glb`、`soccer-women.glb`。
- `*.uv_mapping.json` 的 `source_model` 应与 public 模型文件名一致。

## UV 映射生成

从 GLB 生成 UV 映射：

```powershell
node scripts/generate-glb-uv-mapping.mjs `
  --model public/models/football-jersey-crop-top-two-tone.glb `
  --template templates/football-jersey-crop-top-two-tone/W-M.template.json `
  --out templates/football-jersey-crop-top-two-tone/W-M.uv_mapping.json
```

生成后必须在 `templates/index.js` 中 import 并注册到对应模板的 `uvMapping`。

## CLO 模板导入

从 CLO/Photoshop 分裁片导出目录导入 Web 模板：

```powershell
node scripts/import-clo-template.mjs `
  --source "S:\path\to\参数数据" `
  --template-id W-M `
  --category football-jersey-crop-top-two-tone `
  --panel-order up-front,up-back,under-front,under-back,left-sleeve,right-sleeve,collar
```

脚本输出：

- `templates/<category>/<templateId>.template.json`
- `public/templates/<category>/...`

如果该模板支持 3D 预览，再运行 UV 映射生成脚本。

## 新增品类 Checklist

1. 先确定英文 category slug。
2. 将模板 JSON 放到 `templates/<category>/`。
3. 将裁片图和遮罩放到 `public/templates/<category>/`。
4. 将 GLB 放到 `public/models/<category>.glb`。
5. 生成 `templates/<category>/<templateId>.uv_mapping.json`。
6. 在 `templates/index.js` 注册 `template`、`uvMapping`、`publicAssetBase`、`defaultModelUrl`、`defaultPanelId`。
7. 在 `src/model.test.js` 添加路径和 UV 映射断言。
8. 运行 `npm test` 和 `npm run build`。
