# 2026-08-13 登录界面原型记录

> 历史记录说明：本文记录的是 2026-08-13 的原型阶段。登录和注册现已接入真实认证接口，当前实现与最新状态请以 `项目记录/2026-10-07-当前功能实现记录.md` 及 `项目实现思路/登录注册与认证功能实现思路.md` 为准。

## 当前完成内容

- 新增独立登录界面原型，用于后续认证接入前的视觉和交互确认。
- 登录界面采用大面积留白、系统字体、浅色玻璃材质、低饱和背景和少量苹果系统色点缀。
- 表单包含邮箱、密码、保持登录、忘记密码和进入原型入口。
- 原型阶段登录行为仅做前端校验；该限制已在后续版本中移除。

## 当前边界

- 原型阶段没有接入真实认证；当前版本已接入后端认证 API。
- 原型阶段没有调用后端 API；当前版本已调用注册、登录、当前用户和退出登录接口。
- 原型阶段没有保存 token、session 或用户资料；当前版本已支持 JWT/token、本地会话存储和数据库用户资料。
- 现在没有新增路由依赖。
- 登录原型通过 `?screen=login` 打开；默认仍进入现有编辑器，避免影响当前工作流。

## 维护结构

- 页面组件：`frontend/src/pages/LoginPrototype.jsx`
- 独立样式：`frontend/src/styles/login.css`
- 原型入口：`frontend/src/App.jsx`

## 原型阶段后续认证接入点（已完成）

- `LoginPrototype` 的 `handleSubmit` 已替换为真实登录 API 调用。
- `App` 已使用认证状态判断登录、注册、加载和编辑器入口。
- 已增加 token 存储、当前用户检查和后端 Redis session 校验。
- 已处理登录成功、登录失败、加载中、账号停用和会话过期状态。
