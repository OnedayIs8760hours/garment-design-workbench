# 2026-08-13 登录界面原型记录

## 当前完成内容

- 新增独立登录界面原型，用于后续认证接入前的视觉和交互确认。
- 登录界面采用大面积留白、系统字体、浅色玻璃材质、低饱和背景和少量苹果系统色点缀。
- 表单包含邮箱、密码、保持登录、忘记密码和进入原型入口。
- 当前登录行为仅做前端原型校验：输入任意邮箱和密码即可临时进入现有编辑器。

## 当前边界

- 现在没有接入真实认证。
- 现在没有调用后端 API。
- 现在没有保存 token、session 或用户资料。
- 现在没有新增路由依赖。
- 登录原型通过 `?screen=login` 打开；默认仍进入现有编辑器，避免影响当前工作流。

## 维护结构

- 页面组件：`frontend/src/pages/LoginPrototype.jsx`
- 独立样式：`frontend/src/styles/login.css`
- 原型入口：`frontend/src/App.jsx`

## 后续认证接入点

- 将 `LoginPrototype` 的 `handleSubmit` 替换为真实登录 API 调用。
- 将 `App` 中基于 `screen=login` 的原型入口替换为正式认证状态判断。
- 增加认证状态存储，例如独立的 `authStore` 或后端 session 检查。
- 根据后端返回结果处理登录成功、登录失败、加载中和权限不足状态。
