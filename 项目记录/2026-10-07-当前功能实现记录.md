# 2026-10-07 当前功能实现记录

## 项目当前状态

woda Design 已形成“浏览器裁片设计 → 设计包导出 → Photoshop 还原”的可运行闭环，并已接入基础账号认证。当前前端可以独立启动进行设计编辑；启用后端、数据库和 Redis 后，可以使用登录注册和会话校验。

## 已实现功能

### 1. 账号认证

- 注册新账号：用户名、至少 8 位密码、可选职位。
- 登录：用户名和密码校验，支持“保持登录”。
- 登录状态恢复：启动时读取本地 token，并调用 `/api/auth/me` 验证当前用户。
- 退出登录：调用后端退出接口并清理浏览器中的 token。
- 后端使用密码哈希、JWT 访问令牌和 Redis 会话校验；用户资料存储在数据库中。
- 认证接口包括 `/api/auth/register`、`/api/auth/login`、`/api/auth/me` 和 `/api/auth/logout`。

### 2. 模板和裁片编辑

- 从模板 JSON 加载品类、尺码、裁片顺序、裁片边界、遮罩、辅助线和素材路径。
- 支持在多个裁片之间切换编辑，当前模板资源与 React 组件解耦。
- 当前仓库包含足球球衣模板及双色短款模板入口，并提供对应裁片图片、遮罩和 GLB/UV 数据。
- 支持切换模板，并将选择结果写入浏览器存储。

### 3. 素材、文字和底色

- 上传本地图片，读取图片尺寸并加入素材清单。
- 在当前裁片放置图片素材，可调整位置、尺寸、旋转、透明度和翻转。
- 添加姓名、号码等文字元素，可编辑字体、字号、颜色、描边、透明度、位置、尺寸和旋转。
- 使用色板或取色器设置当前裁片底色，也可以将底色应用到全部裁片。
- 支持清理用户上传素材及其对应图片元素。

### 4. 图层和编辑操作

- 查看当前裁片的元素图层，支持选中、上移、下移和删除。
- 支持撤销最近的设计修改，并限制撤销历史长度。
- 支持清空当前设计，重新开始编辑。
- 设计修改自动保存到当前登录用户的后端设计草稿接口。
- PostgreSQL 持久化完整设计 JSON，Redis 缓存最近草稿；按用户和模板隔离数据。
- 草稿按用户、模板和订单号独立保存，草稿箱可以列出历史草稿并打开继续编辑。
- 保存草稿时将完整设计状态序列化为 JSON 快照，包含模板、订单号、尺码、底色、素材清单、各裁片状态和全部元素；PostgreSQL 的 JSONB 与 Redis 缓存保存同一份快照。
- 打开草稿时先读取云端 JSON，再反序列化、校验模板和裁片结构、补齐模板元数据后恢复到工作台；网络异常时使用 `localStorage` 中的序列化快照兜底。
- “新建设计”会生成新的订单号并创建空白状态，不读取旧草稿内容；旧订单仍保留在个人草稿箱中。
- 个人草稿箱使用固定根路径 `/`；进入编辑器时才追加 `screen=editor&template=...`，返回草稿箱会清除这些编辑器参数。

### 5. 预览、校验和导出

- 提供当前裁片预览、整衣快速预览和基于 GLB/UV 映射的 3D 预览。
- 导出前校验元素越界、缺失图片素材引用和空文字等问题。
- 生成包含订单、模板、裁片、元素、字体、素材引用和校验结果的设计 JSON。
- 下载设计包 ZIP：JSON 写入 `manifest.json`，图片素材写入 `assets/`，供 Photoshop 脚本继续处理。

### 6. Photoshop 与后端基础能力

- Photoshop JSX 支持从 PSD 导出裁片 PNG、遮罩和模板 JSON。
- PowerShell/Photoshop COM 流程支持读取设计包并还原到目标 PSD。
- FastAPI 后端提供健康检查、认证路由、CORS 配置和数据库/Redis 连接配置。
- 后端已增加 RustFS（S3 兼容）对象存储服务层，支持自动建桶、图片上传、对象信息、流式读取、预签名下载 URL、删除和健康检查。
- RustFS 对象键按 `users/{user_id}/designs/{order_id}/assets/` 隔离，所有素材接口都要求登录并校验对象归属。

## 当前边界和待完善项

- 设计草稿已绑定到登录用户并保存到 PostgreSQL，Redis 用于缓存；订单管理、历史版本和素材对象存储仍未拆分建设。
- 当前完整设计 JSON 仍包含在单条草稿记录中，图片素材尚未迁移到独立对象存储。
- 登录页中的“忘记密码”目前只是界面入口，尚未接入找回密码流程。
- 认证依赖 PostgreSQL、Redis 和 `JWT_SECRET_KEY` 配置；未启动依赖服务时无法完成真实登录。
- Photoshop 还原仍要求 Windows、Photoshop 及符合约定的 PSD 图层结构。
